# Binary Shape Generation

## Overview

This project demonstrates the generation and visualization of basic geometric shapes as binary images using MATLAB.

The implementation focuses on representing shapes directly as pixel matrices and using mathematical conditions to determine which pixels belong to a shape.

The project provides a simple introduction to binary image representation, geometric modeling, and pixel-based shape generation.

## Objective

The main objective is to generate geometric shapes programmatically as binary images.

The implementation focuses on:

- Binary image representation
- Pixel-based image generation
- Geometric shape modeling
- Mathematical conditions for shape boundaries
- Filled and non-filled shapes
- Image visualization
- Matrix-based image processing

## Binary Images

A binary image contains only two possible pixel values.

Typically:

- `0` represents the background
- `1` represents the foreground or object

Binary images can therefore be represented directly using matrices.

For example:

```matlab
binaryImage = zeros(100,100);
```

creates a binary-style image with an initially empty background.

Pixels can then be assigned to represent a geometric object.

## Geometric Shape Generation

The shapes are generated by evaluating mathematical conditions for individual pixel coordinates.

For each pixel position $begin:math:text$\(x\,y\)$end:math:text$, the program determines whether the pixel belongs to the desired shape.

The general process is:

    Create image matrix
          ↓
    Generate pixel coordinates
          ↓
    Evaluate geometric condition
          ↓
    Assign foreground pixels
          ↓
    Display binary image

This approach allows geometric objects to be generated without manually specifying individual pixels.

## Circle Generation

A circle can be described mathematically using:

$begin:math:display$
\(x\-x\_c\)\^2\+\(y\-y\_c\)\^2\=r\^2
$end:math:display$

where:

- $begin:math:text$x\_c$end:math:text$ is the x-coordinate of the center
- $begin:math:text$y\_c$end:math:text$ is the y-coordinate of the center
- $begin:math:text$r$end:math:text$ is the radius

For a filled circle, pixels satisfying:

$begin:math:display$
\(x\-x\_c\)\^2\+\(y\-y\_c\)\^2 \\leq r\^2
$end:math:display$

are considered part of the shape.

This allows a circular region to be generated directly from its mathematical definition.

## Square Generation

A square can similarly be generated by defining limits for the x- and y-coordinates.

For a filled square, pixels inside the specified coordinate range are assigned to the foreground.

This demonstrates how simple geometric constraints can be translated into binary image regions.

## Filled and Non-Filled Shapes

The implementation can distinguish between different types of geometric regions.

A filled shape contains all pixels inside its boundary.

A non-filled or outline shape represents primarily the boundary of the object.

Conceptually:

    Filled Shape

    ███████
    ███████
    ███████
    ███████


    Outline Shape

    ███████
    █     █
    █     █
    ███████

This distinction is useful when studying object boundaries and binary image representations.

## Pixel-Based Representation

An important aspect of the implementation is that geometric objects are ultimately represented as matrices.

For an image of size $begin:math:text$M \\times N$end:math:text$:

$begin:math:display$
I \\in \\mathbb\{R\}\^\{M\\times N\}
$end:math:display$

Each matrix element corresponds to one image pixel.

The geometric definition is therefore converted into a discrete pixel representation.

This demonstrates the relationship between continuous mathematical geometry and discrete digital images.

## Visualization

The generated binary shapes are visualized as images in MATLAB.

Displaying the matrices makes it possible to inspect:

- Shape geometry
- Object boundaries
- Filled regions
- Pixel resolution
- Effects of discrete sampling

Visualization is an important part of understanding how mathematical shapes appear when represented using discrete pixels.
